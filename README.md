# MiniMapStatus (故事情情节与战术地图状态栏)

`MiniMapStatus` 是一个专为 **SillyTavern (酒馆)** 或类似 AI 角色扮演前端设计的高颜值、交互式状态栏与战术地图小部件。

它能够自动从 AI 的回复中提取特定的标记内容，解析其中的 YAML 数据，并将其渲染为包含**战术视觉地图**、**角色多维状态卡片**、**动态立绘**、**物品行囊**、以及**快捷行动选项**的精美交互式面板。

---

## 🌟 主要特性

### 1. 🗺️ 战术视觉地图引擎 (Tactical Map Engine)
* **智能环境识别**：根据地图名称关键字（如：*炼丹房、灵草园、操场、酒吧、荒野、血色深渊*等）自动匹配并渲染 20+ 种不同风格的 CSS/SVG 矢量底图或外部高清背景。
* **三维浮动地标**：使用 RPG 风格的悬浮 Emoji 作为地标（支持呼吸灯和阴影跳动动画），点击地标可查看详细描述，并能一键执行“前往该地”的行动。
* **拖拽与缩放**：支持通过鼠标或触摸在 1000x1000 的网格上自由拖拽和缩放地图。

### 2. 🎭 动态立绘与头像引擎 (Portrait & Avatar Engine)
* **高性能单次 DOM 引擎**：立绘扫描采用“快速前置检查 + 单次 DOM 遍历”架构，无标签时 0.01ms 瞬时跳过，彻底解耦角色字典数量与页面遍历开销，哪怕配置数百个角色也始终流畅如初。
* **智能差分与拆分匹配**：支持多形态/差分立绘的精准匹配与智能平滑回退。
  * 例如：标签 `【立绘弗兰克脱衣】` 会优先匹配 `"弗兰克脱衣"` 专属立绘；若未配置，则自动平滑回退至主角色 `"弗兰克"`。
  * 具备空格自动过滤容错能力（如 `【立绘 弗兰克穿衣 】`）。
* **立绘自动注入与灯箱预览**：文本中出现 `【立绘角色名】` 时会自动注入预设的高清大立绘，自带移动端/PC 自适应高度与优雅的渐变 mask 边缘羽化效果，并支持点击唤起高清灯箱（Lightbox）原图预览。
* **动态头像与背景映射**：配置 `PORTRAIT_MAP`、`AVATAR_MAP` 与 `BACKGROUND_MAP` 可轻松为不同角色与地点绑定高清立绘、小地图头像及战术底图。

### 3. 📊 多维状态展示卡片
* **势力与敌友色彩**：将角色自动归类为 **盟友 (Ally)**、**中立 (NPC)** 或 **敌人 (Enemy)**，并渲染为具有各自专属渐变底色和高亮框线的紧凑版卡片。
* **智能徽章系统**：
  * **物品徽章**：检测到 `[物品名]` 格式时自动生成精美徽章，且数量超过 5 个时自动折叠，支持一键展开。
  * **地点徽章**：地点或前往路线字段会自动生成带有 📍/🏛️/☯ 等前缀的地点徽章，点击可直接发送“前往该地”指令。
  * **角色徽章**：敌友列表中的角色会自动解析出 Emoji、姓名、状态标签（如 `[重伤]`、`[警惕]`）和行为描述，点击可直接触发“接触该角色”。

### 4. 🎨 6款精致主题自由切换
内置了六种针对不同游戏背景或阅读偏好设计的主题，支持本地持久化保存：
* 🌸 **修仙 (Romantic)**: 古籍温玉与沉香金配色，极其雅致，适合仙侠、古风背景。
* ☀️ **白天 (Day)**: 纯白底色配薰衣草紫点缀，清晰护眼。
* 🩸 **血色 (Jade)**: 暗红与曜石黑交织，适合战斗、绝地或禁地探险。
* 📜 **古典 (Classic)**: 怀旧羊皮纸黄与枯叶褐，富有跑团或历史沉浸感。
* 🌙 **黑夜 (Night)**: 极暗紫罗兰与霓虹渐变，适合赛博朋克或深夜游玩。
* 🍵 **小清新 (Fresh)**: 春水煎茶的嫩绿/茶绿配色，柔和放松。

## 🛠️ 工作原理

`MiniMapStatus.html` 通过 SillyTavern 暴露的全局接口 `getCurrentMessageId()` 与 `getChatMessages()`，在每次收到 AI 回复时自动读取最新消息，并使用 `<maintext>` 与 `<Status_block>` 两个自定义 HTML 标签提取数据：

1. **`<maintext>`** 标签：包含故事正文。小部件会对其进行排版优化，为双引号中的对话、单引号中的物品、以及星号 `*` 包裹的动作描写渲染不同的颜色和字体样式（可在设置中选择“一体式美化”来显示它，或选择“美化状态栏”来隐藏它以保持界面紧凑）。
2. **`<Status_block>`** 标签：包含状态数据的 YAML 代码块。小部件使用 `js-yaml` 库解析并实时刷新状态栏及战术地图。

## 📋 数据格式与规范 (AI 输出标准)

为了让小部件正常工作，AI 的回复必须按照以下结构输出。

### 1. 消息输出模板
```html
<maintext>
这里是 AI 输出的剧情故事、动作和对话正文。
例如：你走进了‘灵草药园’，远处传来了赤魁的咆哮。
*你握紧了手中的碧水剑，警惕地看着四周*
</maintext>

<Status_block>
故事情节:
  时间: "筑基历三百年 晨"
  地点: "灵草药园"
  角色列表:
    - 角色:
        名字: "李长风"
        修为: "筑基初期"
        生命: "95%"
        灵力: "120/150"
        行囊: "[碧水剑] [回气丹] [下品灵石x10]"
        状态: "[健康] [警惕]"
        灵草药园: # 此键名与下方地图标注匹配，将触发战术地图
          - "📍 【药园阵眼】 (500, 500) 阵法最核心的聚灵位置"
          - "🌱 【九叶草田】 (300, 700) 种植了大量珍稀九叶草的区域"
          - "💧 【灵泉井】 (700, 300) 散发着温润泉气的水井"
        盟友:
          - "👱‍♀️ 【林沐雪】 [练气九层] [重伤] 脸色苍白地躺在阵眼旁"
        敌人:
          - "👹 【赤魁】 [练气圆满] [狂暴] 手持大刀在药园外游荡"
  行动选项:
    名字: "李长风"
    选项:
      - "1. 采摘九叶草"
      - "2. 探索灵泉井"
      - "3. 接触林沐雪"
      - "4. 迎战赤魁"
</Status_block>
```

### 2. YAML 特殊字段格式详解

* **行囊 / 装备物品栏**：
  * **格式**：用中括号包裹每一个物品，例如 `"[碧水剑] [回气丹] [下品灵石x10]"`。
  * **渲染**：会自动解析为圆角卡片式的小徽章（`.item-badge`）。
* **战术地图地标 (`TacticalMapEngine` 拦截键)**：
  * **触发机制**：当角色属性下的某个键名与当前场景名称相关，且值是一个数组，且数组成员符合以下格式时，将激活**平面地图渲染**。
  * **正则格式**：`"Emoji 【地点名称】 (X坐标, Y坐标) 地点的描述文字"`
  * **坐标范围**：`X` 和 `Y` 的范围是 `0` 至 `1000`。
  * **示例**：`- "📍 【药园阵眼】 (500, 500) 阵法核心区域"`
* **角色状态表 (盟友 / 敌人 / NPC)**：
  * **触发机制**：属性键名包含 `盟友`、`敌人`、`NPC`、`ally`、`enemy` 等字眼。
  * **正则格式**：`"Emoji 【角色名】 [标签1] [标签2] 角色的具体状态描述"`
  * **示例**：`- "👹 【赤魁】 [练气圆满] [狂暴] 正虎视眈眈地看着你"`

## ⚙️ 部署与使用方法

1. **导入酒馆 (SillyTavern)**：
   * 将 `MiniMapStatus.html` 文件存放在本地目录。
   * 可以通过 SillyTavern 的 **Iframe (或网页阅读器) 插件/扩展** 将此 HTML 加载为悬浮窗或侧边栏栏目。
   * 也可以将其作为快速回复 (Quick Reply) 的 Web 页面，使用酒馆自带的网页小部件（Webpage Viewer）打开。
2. **配置立绘与头像**：
   * 用文本编辑器打开 `MiniMapStatus.html`，定位到 `window.PORTRAIT_MAP`（第 2316 行左右）。
   * 根据需要在 `PORTRAIT_MAP` 里添加 `"角色名字": "立绘图片直链"`。
   * 在 `AVATAR_MAP` 里添加 `"角色名字": "小头像图片直链"`。
   * 在 `BACKGROUND_MAP` 里添加 `"场景名字": "地图底图图片直链"`，当战术地图键名匹配该场景时，将自动用该图作为地图背景。
3. **设置面板交互**：
   * 点击状态栏右上角 ⚙️ 按钮，可以调整：
     * **显示模式**：`一体式美化` (带正文) 或 `美化状态栏` (隐藏正文，适合作为纯状态栏 iframe 挂件)。
     * **行动点击处理**：
       * `发送到酒馆聊天框`：点击地图地标、角色卡片或行动选项时，将行动文本填入酒馆输入框，供玩家确认后再发送。
       * `点击直接执行`：点击后立即触发发送，并让 AI 产生新回复。

## 📝 系统提示词 (System Prompt) 模版

为了保证大模型能够稳定、正确地输出小部件所需的数据格式，请将以下提示词添加到 SillyTavern 的 **System Prompt** 或 **Character Note** 中：

```markdown
# 状态栏输出指令

在你的每次回复中，你必须将回复内容严格分为两个部分，分别包裹在相应的 HTML 标记中：

1. 包裹在 <maintext></maintext> 中：你的剧情故事正文描写、NPC 的对话和动作。
2. 包裹在 <Status_block></Status_block> 中：使用 YAML 格式的当前场景与状态数据块，严格遵循以下 schema。

## Status_block YAML Schema 规范：

<根节点名称>:
  时间: "<当前剧情的时间或日期，如：清晨/正午/深夜>"
  地点: "<当前玩家所在的总体场景名称，如：灵草药园>"
  角色列表:
    - 角色:
        名字: "<主角姓名>"
        修为: "<属性值>"
        生命: "<如：90%>"
        灵力: "<当前值/最大值>"
        行囊: "[物品A] [物品B] [物品C]" # 用 [] 分离每个物品
        状态: "[负面或正面状态，如：健康/中毒]" 
        <当前地点名称>: # 必须与上面的“地点”或当前所处微场景一致
          - "Emoji 【微地点名称】 (X坐标, Y坐标) 详细的静态描述" # 坐标范围 0-1000，例如："📍 【药园阵眼】 (500, 500) 阵法最核心的聚灵位置"
          - "Emoji 【微地点名称2】 (X坐标2, Y坐标2) 描述2"
        盟友: # 选填，若无则空。键名包含 盟友/ally
          - "Emoji 【盟友姓名】 [标签1] [标签2] 盟友当前的行为或神态描述" # 例如："👱‍♀️ 【林沐雪】 [重伤] 脸色苍白地躺在一旁"
        敌人: # 选填，若无则空。键名包含 敌人/enemy
          - "Emoji 【敌军姓名】 [标签1] [标签2] 敌人当前的行为描写" # 例如："👹 【赤魁】 [狂暴] 手持大刀游荡"
  行动选项:
    名字: "<主角姓名>"
    选项:
      - "1. <可执行的行动描述>"
      - "2. <可执行的行动描述>"
      - "3. <可执行的行动描述>"

## ⚠️ 绝对禁忌与注意事项：
1. 不要输出任何 Status_block 之外的解释文本。
2. 严格遵循 YAML 的缩进格式。如果字符串中包含双引号，用单引号包裹该字段，或者对双引号进行转义。
3. 地图坐标格式必须严格为 `(X, Y)`，X 和 Y 必须是整数，且在 0 - 1000 之间。
4. 角色状态卡中的人物名字必须使用双括号 `【角色名】` 包裹，状态标签使用中括号 `[标签]` 包裹。
```
