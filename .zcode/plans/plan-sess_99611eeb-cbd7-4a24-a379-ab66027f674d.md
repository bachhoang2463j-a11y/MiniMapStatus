# Demo 验证：语义 JSON + 本地渲染器（独立大地图 · 方案 B）

## 已敲定的架构（背景）
- **方案 B**：绘图 LLM 只输出紧凑的「地理+地标一体」语义 JSON（约 0.6~1.5K tokens），本地渲染器生成 demo 级 SVG
- **独立大地图**：绘图 LLM 完全负责大地图（含地标），数据不注入正文上下文，纯玩家参考；状态 LLM 只管小地图等活数据（独立大地图开启时，提示词与注入中剔除大地图段）
- **生成**：手动按钮 + 智能提示——解析正文 AI 每楼输出的 `【 📍 悉尼 · ...】` 标题行提取地点名，匹配不到已有地标时提示「进入新区域，建议更新」；**重绘按钮永远保留**
- **更新**：增量合并（旧 JSON + 最近剧情 → 保留旧地点、追加新地点）
- **当前位置**：实时匹配正文地点名（如"澳大利亚酒店"）→ 高亮脉冲标记，不重绘、不注入

## 本轮实现：重写 `demo-bigmap.html`

### 1. 语义 JSON DSL（两份示例数据）
- **城市图**（悉尼剧情风）：城墙轮廓/塔楼/城门、河流、道路网、桥梁、街区色块、建筑图元（城堡/教堂/民居/广场/码头/船只）、树木、城区标签、emoji 地标（10-90 百分比坐标）
- **大陆图**（维兰大陆）：海洋、大陆轮廓、雪原、森林、山脉、沙漠、火山、平原、湖泊、道路、王都/要塞/港口、罗盘

```json
{
  "style": "flat",
  "terrain": [...], "outline": "M...", "gates": [[x,y]], "towers": [[x,y]],
  "river": "M...", "roads": ["M..."], "bridges": [...],
  "features": [{ "type": "castle", "x": 500, "y": 258 }, ...],
  "labels": [...],
  "markers": [{ "emoji": "🏰", "name": "领主城堡", "x": 50, "y": 25, "desc": "..." }]
}
```

### 2. 渲染器 `renderMapJSON(json) → SVG`
- 纯函数，两种风格预设：`flat`（简约平面）/ `parchment`（羊皮纸噪点+排线+粗笔触）——调色板、笔触、纹理、滤镜、罗盘/比例尺全部代码固定
- 图元库复用现有手搓 SVG 的元素代码（每个 feature type 一个绘制函数）

### 3. 交互演示（验证四个核心卖点）
- **风格即时切换**：同一份 JSON 在 flat ⇄ parchment 间零成本切换
- **当前位置高亮**：模拟地点字段（含解析 `【 📍 悉尼 · 澳大利亚酒店 - 总督套房】` 格式），匹配地标名 → 金色光环脉冲，切换即时生效
- **增量合并**：「模拟新剧情」按钮 → 展示追加的 JSON 片段（如新发现"歌剧院"）→ 合并重渲染，旧地理/地标严格不变
- **JSON 成本可视化**：可展开查看当前 JSON 与字符数/估算 token，对比手搓 SVG 体积（预期 ≤ 1/5）

### 4. 保留现有交互
拖拽平移、滚轮缩放、地标 tooltip、重绘按钮

## 验收标准
- 两种风格渲染效果不低于现有手搓 demo
- JSON 体积 ≤ 手搓 SVG 的 1/5；增量合并后旧内容零变化；位置高亮即时切换
