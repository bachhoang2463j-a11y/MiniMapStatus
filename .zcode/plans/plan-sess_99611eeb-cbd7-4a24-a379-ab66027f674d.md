# 独立大地图：JSON 生成可靠性加固

## 先修正上次的误判

上次我把报错归因为「LLM 转录长数组时掉逗号」，把提示词加固排在最低优先级。重读代码后发现**主因更可能是提示词自己教坏了 LLM**：`buildMapArtSystemPrompt` 的 JSON 模板里有 4 行 `//` 行内注释（`"ground": "field",  // 陆地底色…` 等）。LLM 照抄这种 JSONC 风格后，注释若落在数组最后一个元素之后，`JSON.parse` 报的正是 `Expected ',' or ']' after array element` —— 与报错一字不差。掉逗号是次因（merge 要求重抄整张旧图，输出随历史增长）。两者都要治。

**上次还漏了一个洞**：`saveMapArt` 无条件覆盖 `$mms_map_art`，没有任何备份。一次退化的合并/重绘就能永久销毁累积的地图。你已确认要加备份撤销。

## 改动清单（全部在大地图模块内）

### A. 提示词：不再教 LLM 写非法 JSON（`buildMapArtSystemPrompt`）
- JSON 模板**删掉全部 `//` 注释**，字段解释移到独立的「字段说明」小节
- 补上 `bays` 字段文档（渲染器已支持但提示词从未提及，属实现/契约不一致）
- 新增严格格式规则：禁注释、禁尾随逗号、数组元素间必须有逗号、**输出紧凑单行 JSON**（无缩进换行，体积直接减半）

### B. 解析容错 + 重试学习（`parseMapArtOutput` / `generateMapArt`）
- 新增 `mmsRepairJsonText(text)`：**字符串感知**的扫描器（跟踪 in-string 与转义状态），只在字符串外修复——剥 `//` 与 `/* */` 注释、删尾随逗号、在 `}`/`]`/`"`/数字 紧邻 `{`/`[`/`"` 处补逗号、全角 `，：` 转 ASCII。字符串内的中文、`//`、引号一律不动
- `parseMapArtOutput`：先原样 parse，失败才 repair 后重试一次，成功时 `console.info` 标注「已自动修复」；仍失败则抛出原始错误（保留 position/line 便于定位）
- 三次重试不再用同一份提示词：第 2/3 次追加 `<上次输出失败原因>`（错误消息 + 出错行摘录）并要求严格合法紧凑 JSON。这条本身就能救回本次这类失败

### C. 增量更新改为 patch 协议（纯追加）
- 输入仍发旧图完整 JSON（让 LLM 知道哪些位置已占）；**输出只要新增部分**：
  `{"add":{"markers":[…],"features":[…],"houses":[…],"trees":[…],"terrain":[…],"roads":[…],"districts":[…],"labels":[…]},"name":"可选新图名"}`
- 输出从 3~5KB 降到 300~600B：截断与语法错误概率断崖式下降，且**旧图结构上不可能被破坏**
- 新增 `mergeMapArtPatch(base, patch)`：本地深拷贝后各数组 concat，markers 按名称去重（旧的胜出），`name` 仅在显式给出时替换
- 空 patch（本轮无新地点）**不算失败**：提示「本轮未发现新地点」并保留旧图
- `full`（整图重绘）仍需输出完整 JSON，所以 A/B 两项对它依然必要

### D. 备份与撤销
- `$mms_map_art` 升级为 `{ json, prev, ts }`；`saveMapArt` 覆盖前把当前 json 存入 `prev`（单步）；`loadMapArt` 兼容旧结构
- 卡片工具栏在 `prev` 存在时显示「↩︎ 撤销上次」→ `undoMapArt()`：json 与 prev 互换后保存、原地刷新、广播事件
- 退化保护：`full` 模式新图地标数 < 旧图 50%（且旧图 ≥4 个）时 `confirm()` 让你决定是否采用

### E. sanitize 加固（防止「能解析但渲染崩」）
- markers 按名称去重（当前无去重，LLM 重抄旧地标会出现同名 emoji 成对显示）
- 几何校验：坐标对必须是 2 个有限数字（towers/gates/houses/trees/ridge）；`river`/`roads[]`/`bays[]`/`outline.d`/`terrain[].d` 必须是以 M/m 开头的字符串，否则丢弃该条
- 补 `towers`/`gates`/`bays` 容量上限；`features[].type` 限定为渲染器支持的 15 种（否则命中 `default: ''` 静默空绘）
- 实际发生截断/丢弃时 `console.warn` 记录条数，不再完全静默

### F. max_tokens 下限
绘图调用改用 `Math.max(cfg.maxTokens || 4096, 8192)`（仅此次请求生效，不动你的全局设置、不加新 UI）——整图重绘的完整 JSON 有足够输出余量。

  - 撤销：save → undo → json/prev 正确互换
