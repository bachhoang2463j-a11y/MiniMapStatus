# 第一步：大地图 LLM 底图效果 Demo 页（先看效果，再决定集成）

## 交付物
新建独立文件 `D:\Project\MiniMapStatus\demo-bigmap.html`（不动 MiniMapStatus.html，纯预览用，浏览器直接打开）。

## Demo 内容

**底图**：由我手工模拟「LLM 单段式管线」的输出风格（即最终提示词会要求 LLM 产出的那种 SVG）：
1. **城市·简约平面风** —— 色块街区 + 道路 + 河流 + 城墙，扁平配色
2. **大陆/世界·简约平面风** —— 山川/森林/沙漠/海洋地形色块，对应「亚洲/欧洲」类大陆场景键
3. **城市·手绘羊皮纸风**（DND 版风格对照）—— 羊皮纸底 + 噪点纹理 + 粗笔触轮廓，用于风格对比

三张图都按最终提示词的硬性规范绘制：`viewBox="0 0 1000 1000"`、锁定调色板、stroke ≤ 3、无动画、地物色块刻意落在地标坐标附近（保证 emoji 落点视觉合理——这是与 DND 版的关键差异）。

**交互层**（复刻 TacticalMapEngine 的真实机制）：
- emoji 地标用真实数据格式 `Emoji【名称】(x, y) 描述` 驱动，绝对定位百分比叠加在底图上
- 拖拽平移 + 滚轮/按钮缩放（scale 0.5~4）
- 顶栏开关切换「预设底图 / AI 底图」对比效果；场景切换按钮
- 页脚附说明：token 成本、缓存策略、生成时长预期
