# 健壮性 + 提示词第二轮优化

两轮实测反馈 + 本轮新确认的现金规则。已确认的事实基础：页签 emoji 抖动根因（AI 名字覆盖名册 + `formatNodeName:8035` 只剥第 0 位 emoji，前导空格是程序自设的"保住 emoji"约定）；历史其实每轮都写入了（`appendHistory:11763` 无条件 push），只是 `mmsRenderHistoryList` 在 runUpdate 后与切换历史 Tab（`4340`）时都不刷新；本轮 £15 小费扣减是合法记账（团队现金=全员现金池），但要立"会计无裁量权"规则。

## A. 修我上一轮引入的回归（最高优先）

**A1 不完整重述静默删除条目**。全量重述捷径（`return cmdText`）在基底非空时也生效，AI 少写一项=删除。实证：据点防御 `[⚓][伊西丝圣徽石：12(圣域帷幕运行中)][夹层暗门物理死锁]` → AI 只重述第一项（结尾 `)` 判为裸段）→ 走捷径 → **夹层暗门被删**。
修法：捷径仅在基底为空时生效（首次写入，保住 `[⚓]` 装饰前缀）；基底非空一律走逐段规则（裸段命中→对齐数量或不变，未命中→新增，**永不删除**）。删除只能由显式 `[名称-N]` 完成；原样重述仍不翻倍。

## B. 两个点名问题（已确认方案）

**B1 名字锁定名册**：`mmsMergeChar:9934` 固定成员一律用 `rosterEntry.name`，非名册角色才用 AI/base 名字；非名册角色名字以 emoji 开头时补前导空格归一。页签 emoji 稳定、"跳回首屏"消失，外观零变化。
**B2 历史刷新**：`runUpdate` 成功分支（`11763` 后）与 `mmsSwitchSettingTab` 切到 history 时调用 `mmsRenderHistoryList`。diff 范围不动（你的选择）。

## C. 砍 `<固定成员>` 段的前提

**C1 字段白名单**：`mmsMergeChar` 对 AI 输出的名册未定义字段按值形态分类——`[ ]` 包裹→按校验字段套命令协议落地（与导入逻辑 `9185` 一致），否则按自由字段落地。修掉上轮"索恩/爱德华/弗朗索瓦丝卡片显示字面量 `道具: [薄羊皮手套+1]`"。
**C2 精简 user 消息**：`<固定成员>`（`11636` 起）改为 `<成员人设>`——去掉属性键与逐成员字段清单，只留配了 personaPrompt 的成员；整段移到 `<最新剧情>` 之后。省约 400 token。

## D. 程序层健壮性

- **D1 立绘每轮被丢弃**：`9930` 把 `立绘` 放进 reserved 却从不写回 `c`（全文只有模板 `9781` 与 UI `13680` 写它）。后果：名册立绘标签首轮更新后消失，AI 主动输出的 `【立绘弗兰克脱衣】` 也被丢。补 AI > base > roster.portraitTag 优先级。
- **D2 人物模块类型校验**：`10071` 用 `typeof === 'object'`（数组也过）；要求非数组对象且盟友/NPC/敌人为字符串数组，否则保留上轮。
- **D3 行动选项形状校验**：要求 4 条且以 `1.`~`4.` 起头，不合格保留上轮。
- **D4 小地图条目格式**：不匹配 `MMS_MARKER_RE` 的条目在 `sanitizeState` 剔除或补坐标（现在只在渲染层丢弃 `8393`，数据留着每轮回喂，错误自我强化）。
- **D5 场景键白名单归一**：自创场景键映射到最近白名单键或保留上轮键（现在靠 `TacticalMapEngine` 关键词兜底落"昏暗室内"，表现为场景无故突变）。
- **D6 数量后缀容错**：`[伊西丝圣徽石：12(圣域帷幕运行中)]`、`[薄羊皮手套：6副]`、`[福勒溶液：3瓶(已分剂量)]` 现在都落到裸段、数量无法参与增减。支持 `名称：N + 单位/括号备注`。
- **D7 现金 set 丢货币后缀**：`[团队现金:5000]` → `5000`（增减命令保留"美元"）。统一保留基底后缀。
- **D8 大额现金哨兵**：`mmsApplyCashCommand` 中单轮增减超过现有余额 30% 时 `console.warn`（只提示不拦截，供你发现系统性误读）。

## E. 提示词规则（两轮反复违规）

- **E1** 固定成员只在角色列表输出，「人物」只放非固定成员（两轮都出现爱德华/索恩/弗兰克重复）。
- **E2**「人物」只移除已明确退场的条目；关系未决的（蒂莉·迪瓦恩两轮被删）保留并标注状态。
- **E3** 校验字段的值只能是 `[ ]` 清单/命令，禁止句子（上轮载具 `"弹药": "充足"`）。
- **E4** 无变化整项省略，不要输出空字符串（本轮 `"属性": ""` 一堆）。
- **E5** 消耗指令只能针对该字段已有物品（本轮索恩 `"消耗": "[基廷氏杀虫粉-1]"`，粉在载具杂物里，落空）。
- **E6** 敌人栏只列在场或已确认接触的对象（上轮抽象威胁 `🦟【夏盖幼体/跳蚤】`）。
- **E7** 名字沿用当前状态原样（与 B1 双保险）。
- **E8 团队现金会计规则（本轮新增）**：团队现金是全体调查员的现金集合；只有剧情明确描写固定成员作出**带可见金额**的支付时才输出扣减命令，金额以剧情明示为准（外币按年代汇率换算）；剧情没写的钱一分不动。收入同理。LLM 是正文 AI 的会计，无自由裁量权：不得推断、估算、预扣任何开销。
